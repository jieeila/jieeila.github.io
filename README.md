# [字里行间的回响](https://jieeila.github.io)

许知远是一家老旧出版社的编辑，性格内向，终日与稿纸为伴。社里收到一部匿名投稿的小说《墨痕》，文笔青涩，故事却有一股动人的真诚。其他编辑都将其拒之门外，唯有许知远被深深吸引，他决定以笔名“守墨人”给作者写长长的修改意见。

作者笔名“砚边客”，竟真的回复了。一来二去，他们通过信件深入探讨文学与人生，成了素未谋面的知己。许知远在信中是博学而温和的引导者，“砚边客”则是灵动且充满好奇的学生。他们彼此支撑，度过了生活中的许多低谷，一种深厚的情谊在字里行间滋生。

一年后，《墨痕》修改完成，即将出版。社里安排见面会，许知远紧张万分。当他看到台上那位言笑晏晏、他暗恋多年却从未敢搭话的知名插画师林晚时，整个人都愣住了。林晚也看到了台下的他，眼中闪过同样的震惊，随即化为盈盈笑意。原来，最好的共鸣，来自灵魂的共振，而非声音的大小。
